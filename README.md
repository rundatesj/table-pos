# 테이블 POS

7개 테이블 규모의 소규모 매장을 위한 로컬 저장형 PWA입니다.

## 개인정보 보호 방식

- 주문과 매출은 서버나 GitHub로 전송하지 않습니다.
- 모든 운영 데이터는 사용하는 기기의 브라우저 IndexedDB에만 저장됩니다.
- 백업 파일은 AES-GCM으로 암호화됩니다.
- GitHub 저장소에는 앱 소스만 있으며 실제 매출 데이터는 없습니다.

## 사용 방법

1. GitHub Pages 주소를 태블릿에서 엽니다.
2. 브라우저 메뉴에서 홈 화면에 추가합니다.
3. 관리자 탭에서 6자리 PIN을 설정합니다.
4. 메뉴 관리에서 예시 메뉴를 실제 메뉴로 변경합니다.
5. 영업 마감 후 백업 파일을 Google Drive에 저장합니다.

## 기기 이전

기존 기기에서 `.posbackup` 파일을 만든 뒤 새 기기의 관리자 화면에서 복원합니다. 백업 생성 시 설정한 비밀번호가 필요합니다.
